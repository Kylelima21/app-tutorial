# Edge Code Repository App Description

### Background

This application was created as part of the Sage Summer Camp 2026. This provides practice creating a simple app in a thor, running and debugging, building and testing, and publishing it to the Edge Code Repository.

### Function

This application calculates the mean RGB value for each color, as well as the min and max values too.
